# 💜 ZN-AI (Qwen Edition)
> **Zan Intelligence System** — A part of **@ZN.MultiMedia** 🎨

ZN-AI adalah implementasi Model Bahasa Besar (LLM) lokal yang dioptimalkan untuk terminal. Berfokus pada estetika desain **Violet High-Contrast** dan privasi data sepenuhnya.

---

## ⚡ Main Features
- **Aesthetic Terminal Interface**: Tampilan banner retro-modern ala @ZN.MultiMedia.
- **Local Sovereignty**: Berjalan 100% offline menggunakan Qwen 2.5-1.5B Instruct.
- **Ultra-Fast Generation**: Menggunakan optimasi library `accelerate`.
- **no need to use data and internet**: bisa digunakan Offline selama kamu sudah git-clone.

## 🛠️ Installation & Usage

Pastikan kamu sudah memiliki Python 3.10 ke atas.

```bash
# Clone the repository
git clone [https://github.com/zannn15/ZN-AI.git](https://github.com/zannn15/ZN-AI.git)
cd ZN-AI

# Install requirements
pip install -r requirements.txt

# Launch the AI
python main.py
